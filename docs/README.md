# Araştırma belgeleri

İki Katmanlı Hücre İçi Protein Gözetimi projesinin Türkçe v0.3 araştırma notu `RESEARCH_NOTE_TR.md` dosyasında bulunmaktadır.

PDF sürümü hazırlanmıştır: **Protein_Surveillance_Model_TR_v0.3.pdf**. GitHub bağlantısı üzerinden PDF ikili dosyasının aktarılması tamamlanamadığı için bu dizinde henüz yer almamaktadır; belge ayrı indirme bağlantısından temin edilebilir.

Araştırma henüz deneysel olarak doğrulanmamış hesaplamalı bir hipotezdir; klinik talimat değildir.
